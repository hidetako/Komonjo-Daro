Komonjo-Daro

くずし字の古典籍を、翻刻して現代語で読む Windows アプリ。版本・写本のページ画像や PDF を読み込む（画面の切り取りを Ctrl+V で貼り付けても可）と、国立国会図書館の NDL古典籍OCR-Lite がパソコンの中だけで文字を起こし、AI（Claude または GPT。設定で選択）が画像と見比べて誤読を直し、現代語訳・語注・要約を付けます。変体仮名の字母（元の漢字）を添えた翻刻も出ます。判読できない字は ■、推定は〔 〕で示し、自信のない箇所は「不確実」として別に列挙。左右／上下のレイアウト切替、縦書き表示、過去の資料のサムネイル一覧と全文検索、Markdown 書き出し。

Windows 10／11（64bit）・v0.13.5・アプリ本体は無料（MIT）・現代語訳／注釈は利用者自身の API キー（Anthropic または OpenAI）で動作・OCR はオフラインで動作
