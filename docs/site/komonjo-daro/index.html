Komonjo-Daro — 古典籍のページを、読める文章に

Komonjo-Daro は、江戸期以前の和古書・写本・漢籍のページ画像を読み込み、くずし字を翻刻して現代語訳と注釈を付ける Windows アプリです。仕組みは二段構えです。文字を起こす OCR はパソコンの中だけで動き、通信しません。起こした翻刻を画像と見比べて誤読を直し、現代語訳・語注・要約を付ける部分は、設定で選んだ Claude（Anthropic）または GPT（OpenAI）が担当します。

読む画面は、左に古文書・右に読み取り（左右）と、上に古文書・下に読み取り（上下）の 2 つのレイアウトを切り替えられます。翻刻は縦書きにもでき、画像は拡大して字形を確かめられます。

できること

  • 翻刻　jpg・png・tif・jp2・bmp の画像、または PDF（ページ範囲指定可。1 ページ 1 件として登録し、順に処理）から、行ごとにくずし字をテキスト化。読み順も整えます。
  • 校訂　AI が画像と翻刻を見比べ、誤読を直します。直した箇所は「行・OCR・校訂・根拠」の表で確認できます。
  • 現代語訳・注釈・要約　人名・地名・語彙・典拠の語注と、2〜3 文の要約、推定時代。
  • 不確実な箇所の明示　判読できない字は ■、推定を含む字は〔 〕。自信のない箇所は別に列挙し、確実なことのように書きません。
  • 手直しして再実行　OCR の結果を自分で直してから送り直せます。
  • 一覧・検索　読み込んだ資料をサムネイル付きで一覧。タイトル・翻刻・現代語訳・注釈を横断検索。
  • 書き出し　校訂翻刻・現代語訳・注釈をまとめて Markdown で取得。

データの置き場所

画像と結果は、既定で「ドキュメント\Komonjo-Daro」に資料ごとのフォルダとして保存されます。保存先は設定画面で変更でき、既存のデータごと移せます。ログインや会員登録はありません。

ダウンロード（無料）

最新版 0.4.0 を配布ページから入手できます。インストール後、右上の「設定」で Anthropic または OpenAI の API キーを入力すると現代語訳が使えます。各社の現行モデルから選べます。OCR だけならキーは不要です。

初回起動時の警告表示について
初回起動時に「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」で続行できます。配布数が少ないソフトで出る表示で、中身はすべて公開されています。

API の費用について
現代語訳・注釈は、ご自身で取得した Anthropic または OpenAI の API キーで動き、その利用料はご本人に請求されます。1 ページあたりの目安は数円〜数十円（画像を同送するかどうかとページの文字量で変わります）。画像を送らない設定にすると安くなります。

向いている資料・向かない資料
OCR の学習データは版本（木版印刷）と整った写本が中心です。手書きの書状・証文・日記などの近世文書は精度が大きく落ちます。

詳細

仕組み
  • OCR　国立国会図書館の NDL古典籍OCR-Lite（CC BY 4.0）を同梱。レイアウト認識、文字列認識、読み順整序の 3 段で、GPU なしの CPU で動きます。1 ページ数秒〜数十秒。
  • 校訂・現代語訳　Claude（既定 claude-opus-5-5）または GPT（既定 gpt-6.1-sol）に、縮小した資料画像と翻刻を渡し、決まった形式（校訂翻刻・修正一覧・現代語訳・注釈・不確実箇所・要約・推定時代）で受け取ります。
  • 画面　パソコンの中で小さな Web サーバーが動き、Edge または Chrome のアプリウィンドウで表示します。外からは接続できません。
動作要件

Windows 10／11（64bit）。追加のインストールは不要です。現代語訳には Anthropic または OpenAI の API キーとインターネット接続が必要です。NVIDIA GPU があれば OCR を速くできますが、必須ではありません。

通信について

利用状況の収集や外部へのデータ送信は行いません。通信が発生するのは次の 2 つだけです。

  • 現代語訳・注釈の作成：Anthropic API または OpenAI API（設定で選んだ方。翻刻テキストと、設定で有効なら縮小した資料画像を送信）
  • 起動時の更新確認と更新：GitHub

OCR はオフラインで完結します。API キーはパソコンの中の設定ファイルにのみ保存されます。

アップデート

起動時に新しい版を確認し、あれば画面上部に知らせます。「今すぐ更新」を押すとインストーラーを取得してサイレントに入れ替え、自動で再起動します。自動確認は設定で止められます。

よくある質問

料金はかかりますか？
アプリ本体は無料です。現代語訳・注釈に使う API 利用料は、ご自身の Anthropic または OpenAI のアカウントに請求されます。OCR だけなら費用も通信も発生しません。
翻刻は正確ですか？
版本では高い精度が出ますが、誤読はあります。AI が画像と見比べて直した箇所は根拠つきで一覧になり、自信のない箇所は「不確実」として別に示します。最終的な判断は原本の画像で確かめてください。
手書きの古文書も読めますか？
書状・証文・日記のような手書き文書は、OCR の学習データに少ないため精度が落ちます。版本・整った写本向けとお考えください。
画像は外部に送られますか？
OCR はパソコンの中で完結します。現代語訳を作るときだけ、設定で有効なら縮小した画像と翻刻を選んだ社の API に送ります。画像を送らない設定にもできます。
データはどこに保存されますか？
既定で「ドキュメント\Komonjo-Daro」。設定画面で別のフォルダに変更でき、既存データも一緒に移せます。
